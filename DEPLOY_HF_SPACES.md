# Deploy to Hugging Face Spaces

## One-Click Deploy
[![Deploy on Spaces](https://huggingface.co/datasets/huggingface/badges/main/deploy-on-spaces-md.svg)](https://huggingface.co/new-space?template=seppam/job-automation-studio)

## Manual Deploy
1. Go to https://huggingface.co/new-space
2. Name: `job-automation-studio`
3. SDK: Gradio
4. Upload all files (app.py, requirements.txt, README.md, TOOLS/, GENERATOR/, PROFILES/, SITES/, TEMPLATES/)
5. Click "Deploy" → it builds automatically!

## No API Keys Needed!
This app generates automation scripts — users bring their own AI agent.
No API keys required for hosting.
